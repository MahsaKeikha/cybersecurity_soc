# F45 L3 Gold Standard Audit

F45 is eligible for L3 promotion only when the promotion head proves all of the following:

- Five distinct defensive SOC agents for alert triage, evidence, incident coordination, containment planning, and reporting
- Defensive-only scope with explicit authorized-environment checks
- Fail-closed evidence, chain-of-custody, timestamp, ownership, containment-review, legal/privacy, escalation, reporting, conflict, and unresolved-question gates
- Human approval required after automated gates and unable to override blockers
- Unit, integration, and adversarial governance tests
- Eight-scenario held-out defensive reproducibility suite at 100% expected-behavior pass rate
- Minimal and complete clean-checkout examples
- Python 3.10, 3.11, and 3.12 CI green
- Python 3.12 held-out artifact publication
- Version 1.0.0 plus security and reproducibility documentation

L3 means reference-quality reproducibility and reviewability for authorized defensive SOC workflows. It is not a claim of autonomous incident-response authority or permission for offensive activity.
